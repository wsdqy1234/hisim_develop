# Phase 5E.2b 计划：最终 QoS 与收益实验（基于 5E.2a golden 发现修订）

> 前置：5E.2a 已确立 golden 协议（Case ID/config hash/确定性顺序/SHARED_DRAM 全场景）与三 Regime 接口传导律；本计划据此收敛实验空间，聚焦真实瓶颈。

## 核心修订认知（来自 2a）

1. **复用波瓶颈排序（16K）**：L3 写屏障（231ms）≥ DRAM 加载（138ms）≫ HBF 媒体（1.17ms）> 接口差值（≥896 后 <1ms）——**收益实验必须先解 L3 写屏障的归属**（它是本工作负载结构的首要门控）
2. B70 混合放置 0% vs HBFO −32.7%：**放置（哪侧服务复用）比介质速度更重要**
3. 接口仅在 <896GB/s 聚合时进入 TTFT（且仅全 HBF 命中域）
4. 80% 媒体效率假设对 QoS ≤0.6%（HBFO 域）——收益主张不能建立在媒体效率上

## B1：L3 写屏障解耦实验（新增，最高优先）

目的：判定 2a 中 p95 门控（屏障 231ms）是（a）本工作负载结构特有（复用波 re-insert 驱逐→L3 写）还是（b）普适瓶颈。
- 变体：`HISIM_L3_WRITE_MODE=async`（写不阻塞）对照 barrier；无 storage 后端（无 L3）对照；churn 强度扫描（re-insert 量）
- 输出：屏障占比瀑布（barrier on/off × n2/4k/16k golden 工作负载）——**若 async 模式下 B70 混合恢复收益，5E.1 的 0% 结论须再修订为模式依赖**

## B2：放置策略收益阶梯（QoS 主实验）

golden 工作负载 × 放置 {A DRAM / B70 混合 / HBFO 全 HBF} × {n2, n4, agent, 4K, 16K}：
- 每对配 A/B 两类口径（2a P1 协议）：A 类=系统级（V1a 允许不同命中）；B 类=同命中集介质隔离
- 补 N=8/16（需调度支持验证）与 churn/混合负载
- 输出：放置-收益阶梯表（QoS p50/p95/吞吐 + 每 WIN 利用率 + 守恒）

## B3：接口与效率收敛实验（收窄）
